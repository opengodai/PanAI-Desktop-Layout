# 最终实现与验证边界

## 2026-11-07

已测试环境：Ubuntu 26.04.1、GNOME Shell 50.1、Ubuntu Dock 105、Wayland。

- 顶栏时间靠左，中央彩色条 81×13px。实时几何读回 x=919.5、y=9、width=81、height=13，中心 (960,15.5)，顶栏/时钟均可见。
- 12 色平滑呼吸，5 秒一轮。点击彩色文字 PanAI for Arch-GPT 无等待向两侧散开；重新启用后实测 150ms 已处于 dispersing，消除了旧 2 秒停留。
- Dock 自适应范围 15～52px，保留紧凑/垂直居中/透明底板。底板背景、边框、阴影显式移除；单按钮保留反馈。
- 默认启动器为九色点阵，太极八卦扩散含 231 个不同颜色彩点、以原图标中心为中心，取消右移避让。此前多 actor 版实机验证展开与清理。
- 本次优化后使用单个 St.DrawingArea 一次绘制全部彩点，动画仅改变 scale/opacity；模拟测试验证单画布、231 个点、原点/颜色/清理；原生 GJS Cairo API 验证通过。优化版的真实滚动/动画帧率尚未测量，不声称实测性能提升。
- 启用状态、源码和图标安装到用户目录；源码快照按 SHA-256 隔离，供统一即时加载器切换旧会话代码。当前会话临时诊断接口不属于运行依赖或发布内容。

`scripts/check.sh` 包含：配置/schema 检查、JS/Shell 语法、扩展生命周期与会话布局重建、内外居中、内部条宽变化回归、精确 81px、15～52px 自适应、颜色/计时器清理、无停留字母散开、单画布太极动画、隔离的安装/读回/回退测试。测试不截屏、不访问网络、不修改真实桌面设置。
